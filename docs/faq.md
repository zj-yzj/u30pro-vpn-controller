# 常见问题

[中文](faq.md) · [English](faq.en.md) · [主页](../README.md) · [使用说明](usage.md)

以下回答针对 `v1.3.0-alpha.1`（圆屏 version code 7）。兼容条件见[安装前确认](install.md#安装前确认)，实际使用情况见[测试记录](testing.md)。

## 1. 下载源码、构建 APK 或导入插件后就能使用吗？

请从 [Release](https://github.com/zj-yzj/u30pro-vpn-controller/releases/tag/v1.3.0-alpha.1) 下载 Magisk ZIP 或 Android 安装器 APK，按[安装说明](install.md)完成模块安装。安装器装在 U30 Pro 本机，核心在准备时从官方在线下载。

重启后首次 VPN 关闭、订阅为空。在已有 UFI-TOOLS 中导入 `U30ProVPN.txt`，录入自己的订阅后再开启。只构建 APK 或导入网页插件不会安装网关。只想看界面，可以使用[电脑预览](usage.md#在电脑上预览)。

## 2. 能用于其他 U30 Pro 固件、其他随身 Wi-Fi 或 OpenWrt 吗？

目前只支持[安装页列出的固定条件](install.md#安装前确认)，其他固件、硬件和 root 实现暂不支持。请勿关闭 SELinux 或伪造属性绕过检查。

需要移植时，接口、SFP、路由、DNS、启动和关闭恢复都需重新适配，见[设备集成](device-integration.md)。

## 3. “本机服务未连接”“本机授权未通过”或按钮不可用怎么办？

刚开机时先等初始化完成，检查 Magisk 模块是否启用，再重新打开控制页。操作进行中或状态尚未读到时，按钮会暂时禁用。

持续提示“服务未连接”，需要检查 `webbridge` 和后端；“授权未通过”则需核对当前 APK 的签名、摘要、UID 和信任记录。自行重建 APK 会改变摘要。请保留脱敏错误类别反馈，不要放宽私有目录权限或删除 APK 校验来消除提示。

## 4. 退出应用、关闭网页或关闭悬浮入口会关闭 VPN 吗？

不会。要停止代理，请在主页点“关闭 VPN”，等待实际状态更新，并确认热点客户端恢复原厂联网。

开关状态和节点选择会保存，后续启动按保存状态处理。冷启动时的等待和禁用模块的区别见[重启与恢复](install.md#重启重复安装与恢复)。

## 5. 左滑测速怎么用？为什么底部“刷新”与网页“刷新”不同？

圆屏节点页向左滑普通节点，展开“测速”按钮后点击；右滑收起。已选节点也能测速，`Auto` 没有单独测速按钮。

圆屏底部“刷新”测试整份节点列表，网页右上角“刷新”只读取状态和已有结果。测速需 VPN 已开启且实际运行，不会自动开 VPN。操作细节见[节点选择与手动测速](usage.md#节点选择与手动测速)。

## 6. 会后台自动测速吗？`Auto` 如何选择？“未测速”或失败说明什么？

没有后台全节点定时测速。手动整批测速完整结束后，`Auto` 会按本轮成功结果优选节点；手动选中的普通节点保持不变。

“未测速”是尚无结果，失败提示只描述上次测量。结果是延迟（ms），不是带宽。刷新状态不会更新测量时间；本地运行检查和订阅更新验证仍会照常进行，详见[测速与状态读取](usage.md#测速自动选择与状态读取)。

## 7. 订阅支持哪些格式？为什么浏览器能打开，设备更新仍失败？

支持 Clash/Mihomo 风格 inline `proxies` 或节点映射列表。下载要求 HTTPS、443、公网 IPv4 和有效 TLS；远程 provider、纯 IPv6、内网地址或其他格式可能无法使用。

设备的 DNS、证书库和网络路径与电脑浏览器不同，请按提示检查。圆屏只更新已保存链接，新增或更换 URL 在 UFI“订阅”页完成。完整要求见[订阅管理](usage.md#订阅管理)。

## 8. 订阅更新失败会丢失节点或关闭 VPN 吗？

下载、解析或验证失败会保留旧配置；应用阶段失败会尝试恢复。若显示“恢复未完成”或“应用失败”，刷新并核实实际运行与出口，再反馈错误，保留现有数据。

成功更新后，如果原选节点已从新列表中消失，会回到 `Auto` 并提示。VPN 开启时更新会检查一次当前出口 HTTPS，不会因此启用定时测速。

## 9. 悬浮入口为什么不显示？通知和系统授权是否必需？

先检查“更多 → 快捷入口”已开启，系统已允许显示在其他应用上层，再回到解锁的原厂首页等待状态读取。入口在控制页、其他页面、锁屏和息屏时隐藏。

该入口使用 Android 前台服务及其通知。授权页面不可用、固件限制或首页识别变化时，可先用 Magisk Action 或安装器打开控制页，再反馈问题。设置方法见[快捷入口](usage.md#首页悬浮快捷入口)。

## 10. UFI 登录为什么使设备屏幕出现锁定提示？原生应用也要登录吗？

UFI 或原厂 WebUI 登录可能触发设备原有的屏幕锁定提示，项目没有修改原厂锁屏机制。

圆屏应用通过本机控制桥操作，不需要登录 WebUI，也不直接申请 root。网页面板仍需登录已有 UFI，并使用其认证 root 接口。

## 11. 构建需要什么？为什么未签名 APK 或更新后的 APK不能直接使用？

网页需要 Node.js 18+ 和 npm；后端需要 Go 1.27+，完整互操作测试还需 Java；原生应用需要 PowerShell、JDK 17+、Android Platform 35 和 Build Tools 35 或兼容版本。命令见[构建说明](building.md)。

原生构建默认输出未签名 APK。签名需提供仓库外的 keystore、密码文件和 alias；同包更新通常需要相同签名。设备控制桥还固定校验 APK 摘要，重建后需同步信任记录，见[原生 README](../native-manager/README.md)。
