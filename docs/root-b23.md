# B23 root：工具、步骤与核验

[English](root-b23.en.md) · [完整准备流程](setup.md) · [VPN 安装](install.md)

这份记录来自维护者实际使用过的第三方工具包 **`U30Pro_B23_一键Root 永久无线ADB 永久禁用系统更新`**。目标是原版 **MU5358 / U30ProHW1.0 / `U30ProV1.0.0B23`**，不是 B24、U30 Pro AI 或 F50 Pro。

本项目核对了包内脚本；其中 `magisk.img` 与实测设备的 `init_boot_b` 回读一致，`tos.bin` 与 `trustos_b` 回读的对应前缀一致。这能确认这份包与实测设备的关系，不能保证另一台同型号设备的启动链也匹配。本次整理文档没有重新刷写设备。

**工具包不随本项目分发。** UFI-TOOLS 作者在 [2026-06-04 的公开回复](https://github.com/kanoqwq/UFI-TOOLS/issues/97#issuecomment-4624994150)中提供过 [U30 Pro 一键 Root 资源入口](https://www.123pan.com/s/7oa5Vv-h0yD3?pwd=xk9q)，公开提取码为 `xk9q`。

这是有出处的历史入口，但回复没有写明 B23，本次也未能加载网盘目录，尚未确认其当前内容与本地 B23 套件一致；提供链接也不能证明发布者是包内所有文件的原作者。原包的作者与再分发许可仍未确认。取得文件后先核对适用固件和下方文件身份，没有匹配工具和本机备份时不要进入刷写步骤。[B24 的公开工具](https://github.com/SAMYUBA/u30pro-b24-root-kit)不能替代这份 B23 包。

## 先看它会改什么

| 内容 | 已从套件或实测设备确认的行为 |
| --- | --- |
| TrustOS | 自动脚本向 `trustos` 目标写入 `bin/tos.bin` |
| root 启动镜像 | 随后用强制写入命令向 `init_boot` 目标写入 `bin/magisk.img`，然后重启 |
| Magisk | 原包要求配套 `Magisk_28103_面具.apk`，并完成应用提示的环境修复 |
| 无线 ADB、系统更新 | 这些改动已经打进镜像，不能在刷入时分别取消 |
| 备份与恢复 | 说明要求先备份，但自动脚本不备份，也没有配套的原厂恢复镜像或恢复脚本 |

这份镜像内置了每次开机尝试配置 TCP `5555` 的 ADB、放宽 ADB/系统安全属性和禁用更新相关组件的脚本。**VPN 控制器不依赖无线 ADB，也不需要禁用系统更新。** 若不接受这些附带改动，应选择另行验证的 root 方案，不能把这份包当作只增加 root 的工具。

保持无线 ADB 开放会增加设备的管理入口。尤其当 ADB 认证被放宽时，能够访问该端口的其他设备可能获得调试访问；不要把它暴露到公网或转发给不可信网络。本文没有验证所有接口上的端口可达性，也不把 `ro.adb.secure` 的设置尝试等同于所有设备都已关闭认证。

## 1. 准备工具和恢复材料

需要一台 Windows 电脑、一根确认能传数据的数据线，以及以下材料：

| 材料 | 用途 |
| --- | --- |
| 对应 B23 root 套件 | 提供刷写程序、loader、镜像和配套 Magisk APK |
| 套件中的 `刷机驱动_SPD_Driver_R4.20.4201` | 展锐下载模式驱动，按其中对应 Windows 版本的安装程序处理 |
| [Google Platform-Tools](https://developer.android.com/tools/releases/platform-tools) | 刷完后检查 USB ADB、安装 APK；与下载模式驱动分别核对 |
| 自己设备的原始备份和恢复方案 | 刷写前的必要条件；保留原始文件、分区表、活动槽、大小与 SHA-256 |

随附的驱动目录有 Win7、Win8、Win10；没有据此确认 Windows 11、ARM Windows 或所有驱动签名状态。设备管理器应能识别对应的 UNISOC/SPRD 下载设备，系统启动后则另行确认 ADB。不要把“USB 网卡能上网”当成这两种驱动都已就绪。

`搞机助手_V4.9.1` 和“一键安装安卓驱动”是另外的辅助工具，不是 root 本身必需的组成部分；本项目不分发这些 EXE，也不照搬其关闭安全软件的建议。

备份应来自**刷写前的本机**。已经 root 后再读出的 `init_boot`、`trustos` 是修改后的状态，不是原厂恢复镜像。套件里的 `tos.bin` 为 `5,195,528` 字节，实测设备对应 TrustOS 分区为 `6,291,456` 字节；二者不能当作同一种完整备份。

原包没有给出可核实的备份/完整恢复流程。第一次刷机前，需要向工具提供者取得匹配本机的读取、校验和恢复步骤；本文不补写未验证的分区读取命令或救砖承诺。

## 2. 对应的直接插电流程

仅在确认型号、完整固件、启动链、本机备份和恢复方法均匹配后继续。原包的自动脚本不会替你核对这些条件。

1. 完整解压套件，保持 BAT、`bin` 和其他相对路径不变。先安装适合电脑系统的下载模式驱动。
2. 断开数据线，将 U30 Pro 关机。
3. 在套件中打开 **`[直接插电]一键Root.bat`**，看到等待设备后，再把关机的 U30 Pro 接到数据线。
4. 等待脚本结束并查看完整结果；过程中不要拔线。主脚本执行的是下载模式连接、写 TrustOS、强制写 init_boot、重启。
5. 等设备正常启动，确认原厂首页、Wi-Fi 和原厂联网仍正常。若出现 Wi-Fi 能力变化或启动异常，停止后续安装，按本机恢复方案处理。

原包另有“备用2”“备用3”“手动Root”和“短接模式”脚本。它们使用不同的启动/下载模式，不能理解为按顺序全部运行。遇到 `kick reboot timeout`、`wrong command or wrong mode` 时，先保存错误并核对 USB 模式、驱动和设备状态；不要不断重刷。

自动脚本用 `w_force init_boot`，原说明的手动步骤却用 `w init_boot`；材料没有解释差别，不能把两条路径写成已验证等价。脚本也没有固定 `_a` 或 `_b` 后缀，当前证据只确认实测设备的 B 槽镜像；不要自行补后缀、切槽，或假设其他槽位都兼容。强制写入工具的完整内部行为没有审计，本文不声称它只会影响两个物理分区。

短接需要拆机并确认实际硬件上的调试点。本地材料没有足以独立核对的调试点图和完整恢复步骤，因此这里不提供短接位置或自动续刷指令。

## 3. 安装配套 Magisk 并完成修复

原包明确指定 **`Magisk_28103_面具.apk`**，并提示不能随意换成别的版本，否则可能破坏它的运行环境和更新补丁。VPN 安装器要求版本码至少 `28100`，这是最低检查值，不是让你升级这套 root 环境。

1. 从同一套件将配套 Magisk APK 安装到 U30 Pro 本机，确认连接目标无误；电脑与手机上安装 Magisk 都不能代替这一步。
2. 在 U30 Pro 本机打开 Magisk，按它的提示完成环境修复，并按要求重启。不要只看到图标就开始安装 VPN 模块。
3. 重新打开 Magisk，确认显示已安装，环境修复提示已消失，并可使用模块管理。
4. 在可信 root 终端确认 `id` 返回 `uid=0(root)`，`magisk -V` 返回所需版本码，重启后仍成立。具体只读检查见[准备指南](setup.md#已经-root确认实际可用)。

配套 APK 已静态核对为包名 `com.topjohnwu.magisk`、versionCode `28103`、versionName `1e3edb88`，不是只凭文件名判断。已有 USB ADB 时，将 `SERIAL` 换成目标设备序列号，可安装并打开管理应用：

```sh
adb -s SERIAL install "Magisk_28103_面具.apk"
adb -s SERIAL shell am start -n com.topjohnwu.magisk/com.topjohnwu.magisk.ui.MainActivity
```

若配套应用已正常安装，跳过第一行，不覆盖重装。包名相同不证明官方签名，本项目没有核验这份历史 APK 的原作者签名。

如果后续模块不能随开机运行，先检查 Magisk 环境。实测设备曾缺少 `/data/adb/magisk/busybox`；补齐同版本运行文件后才恢复服务启动。这个历史问题不意味着每台设备都应手动复制 BusyBox：优先检查本机的修复结果，来源不明的二进制不要填进去。

## 4. 接上 UFI 和 VPN

root 与 Magisk 准备好后，回到[完整准备流程第 3 步](setup.md#3-安装-ufi-并确认高级功能)：安装 UFI 完整版，确认插件使用的认证 RootShell 可用，再安装 v1.3.0，导入自己的订阅。

`F50PRO通用高级后台` 文件夹中提供的是 UFI 安装材料，目录名不能证明它能给 U30 Pro root。其 UFI 组件应按 [UFI-TOOLS 作者说明](https://github.com/kanoqwq/UFI-TOOLS/blob/http-server-version/User_Doc.md)使用。root 工具、高级后台和本项目安装包分别取得、分别核对；本项目的 MIT 许可不覆盖这些外部文件。
