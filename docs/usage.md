# 使用说明

[中文](usage.md) · [English](usage.en.md) · [返回主页](../README.md) · [FAQ](faq.md)

本页介绍 `v1.3.0-alpha.1`（圆屏 version code 7）的日常操作。首次使用请先完成[安装](install.md)；运行情况见[测试记录](testing.md)。

<a id="目录"></a>

## 使用前确认

安装后首次打开控制页，应为 **VPN 关闭、无节点、未保存订阅**。先在已有 UFI-TOOLS 中导入 Release 的 `U30ProVPN.txt`，录入自己的订阅，等节点出现后再开启。保存订阅不会自动开启 VPN。

## 圆屏主页与退出

通过 Magisk 模块的“操作 / Action”或安装器的“打开控制”进入“VPN 控制”。主页显示开关、实际运行状态和当前出口，下面是“节点”和“更多”。

- 点“开启 VPN”或“关闭 VPN”，等待操作结束，再确认实际状态。启动期间，开关目标和运行状态可能暂时不同。
- 点“节点”选择出口；点“更多”更新订阅、设置快捷入口或退出。
- 主页按返回或点“更多 → 退出”会关闭界面，其他页面按返回回到主页。

**退出界面不会关闭 VPN。** 要停止代理，请在主页点“关闭 VPN”，确认热点客户端恢复原厂联网。

![原生主页、左滑节点与单节点测速示意](assets/native-ui.svg)

## 节点选择与手动测速

1. 主页点“节点”，上下滚动查看列表。点击普通节点即选择它，点击“自动选择”则切回 `Auto`。
2. **整批测速：** VPN 运行时，点节点页底部“刷新”。它会测试当前订阅的全部节点，完成后显示结果。
3. **单节点测速：** 按住普通节点向左滑，展开“测速”按钮后点击；右滑收起。已选节点也能测速，`Auto` 没有独立测速按钮。
4. 单节点测速不切换当前出口。整批测速完整结束后，会按本轮成功结果为 `Auto` 选择节点；手动选中的普通节点保持不变，使用 `Auto` 时实际出口可能随之变化。

测速需要 VPN 已开启且核心运行，点击测速不会自动启动 VPN。操作中控件会暂时禁用；“未测速”表示尚无结果，“上次测速未通过”表示上次测量失败。项目没有后台全节点定时测速。

## 订阅管理

### 圆屏更新已保存链接

进入“更多 → 订阅”，查看保存状态和上次更新时间，点“更新已保存订阅”。圆屏只更新已保存的 URL；新增或更换链接请使用 UFI 网页。

### 网页新增、更换或复用

在 UFI 面板进入“订阅”：

1. 粘贴自己的 HTTPS 链接，点“保存并更新”。
2. 已有链接时，直接点“更新已保存的订阅”即可。
3. 等待完成，检查节点数、更新时间和提示。如果原选节点已不在新列表中，会回到 `Auto`。

下载或解析失败会保留旧配置。应用阶段失败时会尝试恢复；若显示“恢复未完成”，刷新并检查实际运行与出口，再联系维护者。VPN 开启时更新还会检查当前出口 HTTPS。

<details>
<summary>支持的订阅格式与下载要求</summary>

支持 Clash/Mihomo 风格的 inline `proxies` 或节点映射列表；不转换任意客户端格式或远程 provider。输入有体积、深度和节点数限制，并拒绝危险外部文件引用，最终由设备 Mihomo 校验节点协议和字段。

下载要求 HTTPS、443 端口、无 URL userinfo 或 fragment，使用受限的公网 IPv4 解析与连接，并校验 TLS。内网地址、纯 IPv6 源、非标准端口或不兼容格式可能失败。订阅链接可能包含凭据，请私下保管。

</details>

## 首页悬浮快捷入口

进入“更多 → 快捷入口”：

1. 点“授权快捷入口”，在系统设置允许显示在其他应用上层。
2. 返回后点“开启快捷入口”。
3. 回到解锁的原厂首页，点击悬浮按钮打开控制页，拖动调整位置。

入口在其他页面、锁屏和息屏时隐藏，使用 Android 前台服务及其通知。若不显示，先确认授权、开关和首页状态，详见 [FAQ](faq.md#9-悬浮入口为什么不显示通知和系统授权是否必需)。关闭快捷入口不会关闭 VPN。

## UFI 网页面板

首次在已有 UFI 的“插件功能 → 添加插件(.txt文件) → 提交”中导入 Release 的 `U30ProVPN.txt`，登录后即可：

- 开关 VPN，读取目标与实际运行状态。
- 搜索并选择普通节点或 `Auto`。
- 新增、更换或更新订阅。
- 点右上角“刷新”读取状态和已有测速结果。

**网页“刷新”只读状态，圆屏节点页“刷新”才会整批测速。** 当前网页没有独立测速按钮。关闭网页不会关闭 VPN。

UFI 或原厂 WebUI 登录可能触发设备屏幕锁定提示；圆屏应用不需要登录 WebUI，相关说明见 [FAQ](faq.md#10-ufi-登录为什么使设备屏幕出现锁定提示原生应用也要登录吗)。

## 测速、自动选择与状态读取

| 操作 | 网络访问 | 节点选择 |
| --- | --- | --- |
| 状态轮询、网页“刷新” | 读取本地状态，不测速 | 不变 |
| 圆屏单节点测速 | 测指定节点 | 不变 |
| 圆屏整批测速 | 测当前订阅全部节点 | 为 `Auto` 优选，保留手动选择 |
| VPN 开启时更新订阅 | 下载订阅，检查当前出口 HTTPS | 保留仍存在的选择，否则回到 `Auto` |
| 网关运行检查 | 检查本地进程、TUN 和路由 | 不自动选节点 |

测速使用 `https://www.gstatic.com/generate_204`，预期 HTTP 204。显示的是该次延迟（ms），不测带宽；状态刷新不会重新测量。名为 `Auto` 的组也不会在后台持续巡检，只有手动整批测速后才按结果优选。正常 VPN 转发、DNS 和订阅下载仍会使用网络。

## 在电脑上预览

<details>
<summary>无需设备，使用模拟数据查看界面</summary>

需要 Node.js 18+ 和 npm。在仓库根目录运行：

```sh
npm ci
npm run build
npm run preview
```

打开终端显示的地址，默认 `http://127.0.0.1:18771/`；结束时按 `Ctrl+C`。预览只监听本机，使用模拟节点和内存状态，不连接设备。请使用示例数据，不输入真实订阅。

![使用模拟数据的网页离线预览](assets/web-preview.png)

默认产物在 `build/web-ui/`。自定义输出目录、模拟失败场景和 HTTP 测试见[网页 README](../web-manager/ui/README.md)。

</details>
